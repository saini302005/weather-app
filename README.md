# 🌤️ Weather Application

A responsive and interactive Weather Application built using HTML, CSS and JavaScript.

The application uses the Open-Meteo API to fetch real-time weather information for cities around the world.

## 📌 Project Overview

The Weather Application allows users to search for a city and view its current weather information.

Users can also use their device location to automatically get weather information for their current location.
